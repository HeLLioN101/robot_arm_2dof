# 2-DOF Robot Arm

A simple 2-degree-of-freedom robot arm project built with Arduino and motor control software.

## Demo

- [Forward kinematics demo](https://youtu.be/IrzVEaenZzY)
- [Robot arm control demo](https://youtu.be/p3WVW6PrnyY)

## Features

- 2-axis servo-based movement
- Arduino control
- 2D visualization
- Position and motion demonstrations

## Usage

1. Open the Arduino sketch in `scripts/` using the Arduino IDE.
2. Connect the robot arm servos to the configured pins.
3. Upload the sketch and power the arm.
4. Run the control script to move the arm.

## Hardware

- Arduino
- 2 servo motors
- Robot arm frame
- External servo power supply
- Jumper wires
